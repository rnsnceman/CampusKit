# Equipment photo credits

Photos are bundled locally, so there is no third-party image request at runtime. Existing equipment is matched by its model name; no reseed or database migration is required. Unknown models retain the category illustration.

Reference photos illustrate the equipment, not the condition of the college inventory. The tripod is a representative Manfrotto model, the Scarlett picture shows an interface lineup, and the LED panel picture does not depict the whole accessory kit. Those entries are labelled Reference photo in the UI.
